# 할머니, 김치 어떻게 담가요? (김장 시뮬레이터)

해외에서 김치가 그리운 주인공(20대 여자)이 배추부터 수박, 두쫀쿠까지 마음대로 골라 김장을 해 보고,
영상통화 속 할머니에게 평가를 받는 웹 캐주얼 시뮬레이션 게임.

## 게임 흐름
1. **재료 고르기** (3인칭) — 기본 재료 + 엉뚱한 재료, 최대 6개
2. **손질하기** (1인칭) — 통째로 / 포기 / 막썰기 / 깍둑 / 채썰기, 칼질할 때마다 재료가 실제로 잘림
3. **양념 만들기** (1인칭) — 양념통을 눌러 한 숟갈씩
4. **버무리기** (1인칭) — 고무장갑으로 문지르면 재료가 양념색으로 물듦
5. **보관하기** (3인칭) — 바로 먹기 / 김치통 / 항아리
6. **할머니 평가** — 시장에서 할머니가 직접 맛보고 '~도'로 이어지는 유머 반응, 맛 분석은 이때 처음 공개

숨은 레시피 14종은 김치 도감에 모입니다(브라우저 localStorage).

## 기술
- `index.html` + Three.js r128 (CDN) + GLTFLoader, 빌드 과정 없음
- 재료·양념 모델은 `assets/`의 `.glb` 파일을 불러와 사용 (실패 시 코드 모델로 대체)
- 재료 손질: 불러온 메시를 칼질 위치의 평면으로 잘라 조각을 만들고, 잘린 단면을 삼각분할로 채움
- 캐릭터·배경은 코드로 만든 로우폴리 3D (플랫 셰이딩, 캔버스 텍스처)
- 효과음: Web Audio API로 합성

## 실행
정적 호스팅(Vercel 등)에 그대로 올리거나, 로컬에서는 `python -m http.server`로 연 뒤 `http://localhost:8000`에 접속하세요. (`file://`로 열면 모델 파일을 못 불러와 기본 모델로 동작합니다.)
