## 기획 방향
---

이 게임에는 틀린 김치가 없다. 플레이어가 무엇을 넣든 그 조합만의 김치 이름, 그림, 반응이 나오고, 플레이어는 "이번엔 이걸 넣으면 어떻게 될까?" 하며 여러 번 다시 만들어 본다. 정통 김치는 여러 결과 중 하나일 뿐이며, 수박이나 두쫀쿠를 넣은 김치도 실패가 아니라 새로운 발견으로 취급한다.

- 진행을 막는 조건은 최소한으로 둔다. (재료를 하나도 넣지 않은 경우 정도)
- 결과는 점수나 합격 여부가 아니라 김치 이름, 그림, 반응으로 보여 준다.
- 만든 김치는 도감에 모여, 아직 못 만든 김치가 다음 판의 동기가 된다.

## 1. 인트로와 단계별 김장 진행
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

플레이어가 해외에서 김치를 직접 만들어 보겠다는 주인공의 상황을 이해하고, 정해진 순서로 한 판을 진행할 수 있도록 한다. 진행 단계는 재료 선택, 재료 손질(써는 방식), 김장 양념 만들기, 버무리기와 보관, 완성 및 시식을 포함한다. 각 단계는 빠르게 넘길 수 있어야 하며, 손질과 양념에는 기본값을 미리 선택해 두어 플레이어가 고르지 않아도 진행할 수 있게 한다. 첫 출시 범위에는 단일 플레이어의 안내형 이야기 흐름을 포함하며, 다중 플레이어나 자유로운 이야기 분기는 제외한다.

| 단계 | 플레이어 행동 | 진행 조건 |
|---|---|---|
| 인트로 | 상황 확인 | 시작 버튼 |
| 재료 선택 | 재료를 자유롭게 넣기/빼기 | 재료 1개 이상 |
| 재료 손질 | 써는 방식 선택 | 없음 (기본값: 포기 썰기) |
| 양념 만들기 | 소금, 고춧가루 양 조절 | 없음 (기본값: 보통) |
| 버무리기와 보관 | 버무리기, 보관 방법 선택 | 버무리기 완료 (보관 기본값: 김치통) |
| 완성 및 시식 | 김치 이름, 그림, 반응 확인 | 다시 만들기 버튼 |

**수용 기준:**
```
1. ○ 신규 플레이어가 게임을 시작하면 해외에서 김치를 먹고 싶어 직접 만들기로 하는 인트로를 확인하고 첫 단계로 이동할 수 있다.
2. ○ 플레이어가 재료 선택을 완료하면 재료 손질, 양념 만들기, 버무리기와 보관, 완성 및 시식 단계로 순서대로 이동할 수 있다.
3. ○ 재료를 하나도 넣지 않은 경우에만 다음 단계로 이동할 수 없고, "뭐라도 하나는 넣어 보자!" 같은 안내를 확인할 수 있다.
4. ○ 손질, 양념, 보관 단계는 기본값이 선택된 상태로 시작해 플레이어가 바로 다음으로 넘어갈 수 있다.
5. ○ 플레이어가 한 판을 완료하면 결과와 함께 바로 다시 만들기를 시작할 수 있다.
```

## 2. 기본 및 창의적 재료 선택
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

플레이어가 김장 재료와 엉뚱한 재료를 자유롭게 넣어 보는 영역이다. 각 재료에는 좋고 나쁨 대신 맛 성분(짠맛, 매운맛, 단맛, 감칠맛, 엉뚱함)과 색이 있으며, 넣은 재료의 성분이 쌓여 결과 김치의 성격이 정해진다. 재료를 넣을 때마다 김치 그릇의 색과 모양이 바로 바뀌어, 플레이어가 완성 전부터 결과를 상상할 수 있게 한다. 첫 출시에서는 화면에 제공되는 재료 목록 안에서 선택하는 기능을 포함하며, 사용자가 임의의 재료 이름을 입력하는 기능은 제외한다.

| 구분 | 재료 | 맛 성분 | 그릇 변화 |
|---|---|---|---|
| 기본 | 배추 | 기본 바탕 | 초록 잎 |
| 기본 | 무 | 단맛 +1 | 하얀 조각 |
| 기본 | 쪽파 | 매운맛 +1 | 초록 줄기 |
| 기본 | 마늘 | 매운맛 +1, 감칠맛 +1 | 하얀 알갱이 |
| 기본 | 젓갈 | 짠맛 +1, 감칠맛 +2 | 국물 색 진해짐 |
| 창의 | 수박 | 단맛 +2, 엉뚱함 +2 | 분홍빛, 수박씨 |
| 창의 | 두쫀쿠(두바이 쫀득 쿠키) | 단맛 +2, 엉뚱함 +3 | 갈색빛, 피스타치오 조각 |
| 창의 | 민트초코 | 단맛 +1, 엉뚱함 +3 | 민트색 얼룩 |
| 창의 | 치즈 | 감칠맛 +1, 엉뚱함 +2 | 노란 녹은 치즈 |

- 재료 목록과 수치는 데이터 표로 관리해, 나중에 재료를 쉽게 추가할 수 있게 한다.

**수용 기준:**
```
1. ○ 플레이어는 재료 선택 단계에서 기본 재료와 창의적인 재료를 구분해 확인하고, 재료를 한 번 누르면 넣고 다시 누르면 뺄 수 있다.
2. ○ 재료를 넣거나 빼면 김치 그릇의 색과 모양이 즉시 바뀐다.
3. ○ 재료를 넣었다 빼면 맛 성분 합계가 넣기 전 값으로 정확히 돌아온다.
4. ○ 기본 재료만, 창의 재료만, 섞어서 등 어떤 조합으로 넣어도 다음 단계로 진행할 수 있다.
5. ○ 플레이어가 선택한 재료와 맛 성분 합계는 최종 결과에 전달되어 반영된다.
```

## 3. 재료 손질과 양념 만들기
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

배추를 써는 방식을 고르고, 소금과 고춧가루 양을 조절해 김장 양념을 만드는 영역이다. 써는 방식은 결과 김치의 종류(포기김치, 막김치, 깍두기)를 정하고, 양념은 짠맛과 매운맛 성분에 더해진다. 어떤 선택도 틀리지 않으며, 선택에 따라 결과 김치의 이름과 반응이 달라진다. 실제 조리법의 정확한 계량이나 현실의 식품 안전 안내는 첫 출시 범위에 포함하지 않는다.

| 항목 | 선택지 | 결과에 주는 영향 |
|---|---|---|
| 써는 방식 | 포기 썰기 / 막썰기 / 깍둑썰기 | 김치 종류: 포기김치 / 막김치 / 깍두기 |
| 소금 | 적게 / 보통 / 많이 | 짠맛 +0 / +1 / +3 |
| 고춧가루 | 없음 / 보통 / 듬뿍 | 매운맛 +0 / +1 / +3, 김치 색 하양 / 빨강 / 진빨강 |

**수용 기준:**
```
1. ○ 플레이어가 재료 손질 단계에 진입하면 써는 방식 3종을 확인하고 선택을 바꿀 수 있으며, 고르지 않으면 기본값으로 진행된다.
2. ○ 써는 방식을 고르면 그릇 속 재료 모양이 해당 방식(포기, 막썰기, 깍둑)으로 바뀐다.
3. ○ 플레이어는 소금 양과 고춧가루 양을 각각 조절할 수 있고, 조절할 때마다 김치 색이 바뀐다.
4. ○ 고춧가루 없음, 소금 많이 같은 극단적인 선택도 막지 않고 결과에 반영한다.
```

## 4. 버무리기, 보관과 결과 생성
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

손질한 재료와 양념을 섞고 보관 방법을 골라 김치를 완성하는 영역이다. 버무리기는 짧고 손맛 나는 상호작용(문지르기, 여러 번 클릭 등)으로 제공한다. 보관 방법은 김치의 숙성 정도를 정해 결과 이름과 반응에 반영된다. 복잡한 물리 시뮬레이션이나 실제 발효 과정은 포함하지 않는다.

| 보관 방법 | 숙성 정도 | 결과 이름 앞말 예시 |
|---|---|---|
| 바로 먹기 | 겉절이 | 갓 버무린 |
| 김치통 | 적당히 익음 | 새콤한 |
| 항아리 | 푹 익음 | 묵은 |

**결과 생성 규칙:**
1. 숨은 레시피 표에 있는 조합이면 그 레시피의 이름, 그림, 반응을 사용한다.
2. 아니면 맛 성분 중 가장 높은 성분과 숙성 정도, 대표 재료, 김치 종류로 이름을 만든다.
   - 예: 단맛 최고 + 김치통 + 수박 + 깍두기 → "새콤달콤 수박 깍두기"
   - 예: 엉뚱함 최고 + 항아리 + 두쫀쿠 + 포기김치 → "묵은 쫀득 두쫀쿠 포기김치"
3. 성분이 같으면 엉뚱함 → 짠맛 → 매운맛 → 단맛 → 감칠맛 순으로 대표 성분을 정한다.

**숨은 레시피 예시 (첫 출시 6~10개):**

| 조합 | 결과 이름 |
|---|---|
| 기본 재료 5종 + 소금 보통 + 고춧가루 보통 + 포기 썰기 | 할머니 인정 정통 포기김치 |
| 수박 + 두쫀쿠 | 여름밤 디저트 김치 |
| 고춧가루 없음 + 무 + 바로 먹기 | 하얀 겉절이 |
| 치즈 + 고춧가루 듬뿍 | 불닭 치즈 김치 |
| 민트초코 + 두쫀쿠 + 수박 | 편의점 신상 김치 |
| 소금 많이 + 젓갈 + 항아리 | 바다보다 짠 김치 |

**수용 기준:**
```
1. ○ 플레이어가 손질과 양념 만들기를 완료하면 버무리기 단계에서 버무리기 상호작용을 할 수 있다.
2. ○ 버무리기를 완료하면 보관 방법을 고를 수 있고, 고르지 않으면 기본값으로 진행된다.
3. ○ 어떤 재료, 양념, 보관 조합으로 완성해도 이름, 그림, 반응을 가진 하나의 결과 김치가 생성된다.
4. ○ 숨은 레시피 조합으로 완성하면 해당 레시피의 고유 결과가 나온다.
5. ○ 버무리기나 완성 버튼을 연속으로 눌러도 결과는 한 판에 하나만 생성된다.
```

## 5. 시식 반응과 김치 도감
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

완성된 김치를 주인공과 해외 친구가 맛보고 반응하는 영역이다. 반응은 점수나 합격 여부가 아니라 맛 성분에 따른 유머러스한 대사와 표정으로 보여 준다. 만든 김치는 김치 도감에 기록되며, 플레이어는 아직 만들지 못한 숨은 레시피 칸을 보며 다른 조합을 시도한다. 첫 출시에서는 게임 내 텍스트와 간단한 연출로 제공하며, 온라인 순위나 사용자 간 공유 기능은 제외한다.

**반응 규칙 (해당하는 반응을 최대 3개까지 이어서 표시):**

| 조건 | 반응 예시 |
|---|---|
| 짠맛 4 이상 | "켁켁, 너무 짜! 물 좀 줘!" |
| 매운맛 4 이상 | "으아, 입에서 불 나!" |
| 단맛 4 이상 | "이거… 디저트야?" |
| 엉뚱함 3 이상 | "재료가 이상해! 근데 묘하게 손이 가네?" |
| 감칠맛 3 이상 | "오, 감칠맛 제대로인데?" |
| 고춧가루 없음 | "빨갛지 않은 김치도 있구나!" |
| 숨은 레시피 발견 | "새로운 김치 발견!" + 레시피 전용 반응 |
| 해당 없음 | "음… 이게 김치의 맛이구나!" (기본 반응) |

**김치 도감:**
- 숨은 레시피 칸은 처음에 물음표와 짧은 힌트로 표시한다. (예: "여름 과일과 쿠키가 만나면…?")
- 발견한 숨은 레시피와 최근에 만든 일반 김치를 그림과 이름으로 보여 준다.
- 도감 기록은 브라우저에 저장해 새로고침 후에도 유지한다.

**수용 기준:**
```
1. ○ 플레이어가 김치를 완성하면 결과 김치의 이름, 그림, 주인공과 친구의 반응을 확인할 수 있다.
2. ○ 소금을 많이 넣은 조합에는 '켁켁, 너무 짜!'처럼 원인을 짐작할 수 있는 유머러스한 반응이 표시된다.
3. ○ 수박이나 두쫀쿠처럼 일반적이지 않은 재료가 포함된 조합에는 '재료가 이상해!'와 같이 창의적 선택을 반영한 반응이 표시된다.
4. ○ 여러 반응 조건에 해당하면 최대 3개까지 이어서 표시되고, 해당하는 조건이 없으면 기본 반응을 표시한다.
5. ○ 숨은 레시피를 처음 만들면 발견 연출과 함께 도감에 등록되고, 이미 발견한 레시피는 중복 등록되지 않는다.
6. ○ 도감에서 아직 발견하지 않은 숨은 레시피는 힌트와 함께 잠긴 상태로 표시된다.
```

## 6. 게임 상태 관리와 다시 만들기
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

한 판의 모든 진행 정보(현재 단계, 선택 재료, 맛 성분 합계, 써는 방식, 양념, 보관 방법, 결과)를 하나의 게임 상태에서만 관리하고, 화면은 이 상태를 보고 그린다. 재료 성분, 양념 영향, 숨은 레시피, 반응 문구는 코드 안의 조건문이 아니라 별도의 데이터 표로 관리해, 재료와 레시피를 쉽게 늘릴 수 있게 한다. 도감 기록은 한 판의 상태와 분리해 다시 만들기를 해도 유지한다.

**수용 기준:**
```
1. ○ 화면에 표시되는 김치 그릇의 색, 모양, 맛 성분은 항상 게임 상태의 값과 일치한다.
2. ○ 다시 만들기를 하면 한 판의 상태(단계, 재료, 맛 성분, 써는 방식, 양념, 보관 방법, 결과)는 모두 초기값으로 돌아가고, 도감 기록은 유지된다.
3. ○ 데이터 표에 재료나 숨은 레시피를 한 줄 추가하면 코드 수정 없이 게임에 반영된다.
4. ○ 개발 중에는 화면 구석에 현재 단계와 맛 성분 합계를 텍스트로 표시할 수 있다.
```
