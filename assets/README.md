# 재료 에셋

게임이 시작할 때 이 폴더의 3D 모델(.glb)을 불러와서 씁니다.
파일을 Blender 등에서 고쳐서 같은 이름으로 덮어쓰면 게임에 바로 반영됩니다.

- **재료:** 불러온 모델을 손질 단계에서 그대로 평면으로 잘라 조각을 만듭니다. 모양을 바꿔도 썰기가 동작합니다.
  - 길이 방향은 x축으로 두면 됩니다. 크기는 게임이 알아서 맞춥니다 (`index.html`의 재료 데이터 `L` 값 기준).
  - 잘린 단면 색은 재료 데이터의 `inner` 색을 씁니다. 수박·두쫀쿠·민트초코·치즈·파인애플은 `index.html`의 `INNER` 단면 무늬(씨, 초코칩, 구멍 등)를 씁니다. 무늬는 원래 모델 좌표 기준이라 모델 크기·위치를 크게 바꾸면 무늬 위치도 같이 고쳐야 합니다.
  - 정점 색상(vertex color)을 쓰고, 없으면 재질의 기본 색을 씁니다. 텍스처는 쓰지 않습니다.
  - 구멍 없이 닫힌 메시여야 단면이 깔끔하게 채워집니다.
- **양념통:** 모델을 그대로 복제해서 씁니다.
- 파일을 못 불러오면 코드로 만든 기본 모델로 자동 대체됩니다.

| 폴더 | 내용 |
|---|---|
| `ingredients/` | 손질 재료 15종 (기본 10 + 엉뚱 5) — `.glb` 3D 모델 + `.png` 썸네일 |
| `seasonings/` | 양념 12종 (양념통 모델) — `.glb` + `.png` |
| `manifest.json` | 재료 키, 이름, 분류, 맛 성분, 파일 경로 목록 |

- 형식: glTF Binary(.glb)
- 로컬에서 볼 때는 `file://`로 열면 모델을 못 불러오니 간단한 웹 서버로 여세요 (예: `python -m http.server`).
- 단위: 게임 씬 기준 (배추 길이 약 2.5)
- 열어보기: https://gltf-viewer.donmccurdy.com 등 glTF 뷰어, Blender(File → Import → glTF)
